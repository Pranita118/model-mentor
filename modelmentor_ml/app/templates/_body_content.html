🚀 Quick Start — Up & Running in 5 Minutes
1
Upload your dataset
Click the 📂 Data Upload tab (it's the first one, active by default). Drag & drop a .csv, .xlsx, or .json file onto the drop zone — or click it to browse your files. Your data is processed entirely in the browser; nothing is sent to a server.
💡 Don't have data handy? Scroll down on the Upload tab to find built-in Sample Datasets (Titanic, Iris, Housing, etc.) — click any one to load it instantly.
2
Explore the automatic profile
After uploading, the app auto-navigates to 🔬 Profiling. Here you see row/column counts, data types, missing-value percentages, outlier counts, a correlation heatmap, and per-column distributions — all computed instantly.
ℹ️ Use the sub-navigation inside Profiling to jump between Overview, Columns, Correlations, and Distributions.
3
Clean your data
Go to 🧹 Clean to fix common data-quality issues. You can fill or drop missing values, remove duplicate rows, handle outliers, rename/drop columns, change data types, and apply text transformations — all with one click per operation.
💡 Every cleaning action is undoable with Ctrl+Z and re-doable with Ctrl+Y. A live change log shows every step taken.
4
Train machine learning models
Head to 🤖 Models. Select your target column, choose classification or regression (or leave it on Auto-detect), pick one or more algorithms, then click Run Models. Results including accuracy, confusion matrices, and feature importances appear instantly.
⚠️ Make sure your data is reasonably clean before training — missing values in the target column can cause errors.
5
Export or share results
Use 💻 Export Code to download ready-to-run Python code that replicates your pipeline. Use 📄 Report to generate a full HTML report. Use the Share button in the header to copy a shareable link of your current analysis.

📋 Phase Details
📂
Phase 1 — Data Ingestion
Upload your CSV, Excel, or JSON file. Check the summary stats that appear at the top: row count, column count, and data types. If something looks wrong (e.g. a numeric column parsed as text), head to Clean → Type Conversion to fix it.
🔬
Phase 2 — Exploratory Analysis
Use the Profiling tab to understand your data deeply. Look for: high-null columns (consider dropping if >50% missing), skewed distributions (log-transform candidates), highly correlated features (consider dropping one), and columns with very low variance (usually uninformative).
🧹
Phase 3 — Data Cleaning
Address the issues found in profiling: fill or drop nulls, remove duplicates, handle outliers. Always check the Change Log panel to review what you've done. Use Ctrl+Z to undo any mistake.
⚙️
Phase 4 — Feature Engineering
Encode categorical columns before running ML models (ML algorithms require numbers). Apply scaling for distance-based models like KNN and SVM. Create new features (interactions, date parts) to give models more signal.
🤖
Phase 5 — Model Training & Evaluation
Select a target column, pick your task type, choose algorithms, and run. Compare metrics across models. Use the Feature Importance chart from Random Forest to understand which variables matter most.
📄
Phase 6 — Export & Share
Download your cleaned dataset as CSV from the Clean tab. Generate a Python script from Export Code. Create a shareable HTML report from the Report tab. Share the analysis link using the header button.
📑 Tab-by-Tab Reference
📂
Data Upload
Purpose: Load your dataset into ModelMentor.
How to use: Drag a file onto the drop zone or click to browse. Supported formats: .csv, .xlsx, .xls, .json. Files up to several MB work well; very large files (>50 MB) may be slow due to in-browser processing.
Sample datasets: Scroll below the drop zone to find pre-loaded datasets (Titanic, Iris, Housing prices, etc.) — great for exploring features before uploading your own data.
🔬
Profiling
Purpose: Automated exploratory data analysis.
Sub-sections:
  • Overview — shape, dtypes, nulls, duplicates, outlier count, top stats
  • Columns — per-column card with min/max/mean/unique/null%
  • Correlations — colour-coded heatmap of numeric feature correlations
  • Distributions — histograms and bar charts for every column
🧹
Clean
Purpose: Fix data quality issues without writing code.
Operations available:
  • Missing Values — fill with mean/median/mode/custom value, or drop rows/columns
  • Duplicates — detect and remove exact duplicate rows
  • Outliers — remove using IQR or Z-score method per column
  • Columns — rename, drop, reorder columns
  • Type Conversion — cast columns to numeric, string, datetime, category
  • Text Operations — trim whitespace, lowercase, uppercase, regex replace
  • Filter Rows — keep/drop rows matching a condition
💡 The Change Log panel at the bottom of the Clean tab records every operation. You can download the cleaned dataset as CSV at any time.
📊
Dashboard
Purpose: Create custom charts to explore relationships in your data.
How to use: Select X-axis column, Y-axis column (for scatter/line/bar), and chart type. Click Generate Chart. Charts can be saved as PNG via the download icon.
🤖
Models
Purpose: Train and compare ML algorithms on your dataset.
Steps:
  1. Select the Target Column (what you want to predict)
  2. Set Task Type — Auto works well; override if needed (Classification or Regression)
  3. Check the algorithms you want to run (you can pick multiple)
  4. Set the Test Split percentage (default 20%)
  5. Click Run Models — results appear below within seconds
⚠️ Categorical columns must be encoded (e.g. one-hot) before training — use the Features tab first, or the app will auto-encode them as label encoding.
💻
Export Code
Purpose: Get a complete Python script that reproduces your analysis.
The generated code includes: dataset loading, all cleaning operations, feature engineering steps, model training, and evaluation. Copy it or download as a .py file to run in your own environment.
⚙️
Features (Feature Engineering)
Purpose: Transform raw columns into model-ready features without code.
Includes: Encoding (one-hot, label, ordinal), Scaling (standard, min-max, robust), Transformations (log, sqrt, square), Interaction features (multiply two columns), Date parsing (extract year/month/day/weekday), and Custom Formula columns.
🔗
Merge
Purpose: Combine two datasets by a common key column.
Upload a second file, select the key column(s) and join type (inner / left / right / outer), then click Merge. The result replaces your current dataset.
📄
Report
Purpose: Generate a polished, shareable HTML analysis report.
Includes all profiling stats, the cleaning change log, model results, and charts. Click Generate Report to preview, then download as an HTML file to share with colleagues.
✨
AI Assistant
Purpose: Chat with an AI that knows your dataset.
Once data is loaded, the AI has full context — column names, types, counts, nulls, ranges — and can answer specific questions like "which columns have the most nulls?" or "write me Python code to plot the age distribution". Use the quick-prompt chips at the top for one-click common questions.
ℹ️ Fully on-device (no API). Gives dataset-specific answers using your actual column names and real statistics.
💡 Tips & Tricks
💡
Use sample datasets to learn the app
On the Upload tab, load the Titanic dataset. Then walk through every tab — profile the data, clean the Age nulls, engineer the Sex column via one-hot encoding, train a Random Forest, and export the code. This full round-trip takes ~5 minutes and teaches you the whole platform.
⚡
Press numbers 1–9 to jump between tabs instantly
Each tab has a number shortcut: 1 = Upload, 2 = Profiling, 3 = Clean, 4 = Dashboard, 5 = Models, 6 = Export Code, 7 = Features, 8 = Merge, 9 = Report. Much faster than clicking when you're switching frequently.
🧹
Clean incrementally, not all at once
Apply cleaning operations one at a time and check the data preview after each step. This way, if something unexpected happens, you only need to undo one step rather than starting over. The undo stack holds up to 20 operations.
🤖
Run multiple models and compare
Select 3–4 algorithms at once (e.g. Logistic Regression + Random Forest + KNN) and run them together. The results table lets you compare accuracy, precision, recall and F1 side by side in seconds — something that would take hours to set up manually in code.
✨
Ask the AI before you guess
Not sure which model to use or how to handle a specific null pattern? Just ask the AI Assistant. It has full context of your data and will give specific, actionable advice — like "your Age column is 20% null; fill with median grouped by Pclass".
🔄
Re-profile after cleaning
After making significant changes in Clean or Features, switch back to Profiling — it updates live. You'll see the null counts drop to zero, outlier counts change, and distributions shift. This is a great sanity-check before training models.
📊
Use the Dashboard for presentation-ready charts
The Dashboard's charts are rendered with Chart.js and can be exported as PNGs. This is useful for including visuals in presentations or reports outside the app. Combine with the Report tab for a complete exported package.

❓ Frequently Asked Questions
Is my data sent to any server? ▼
No. All data parsing, profiling, cleaning, ML model training, and AI Assistant responses happen entirely inside your browser using JavaScript. Your dataset never leaves your device and no AI API call is required for answering.
What file formats are supported? ▼
ModelMentor supports CSV (.csv), Excel (.xlsx, .xls), and JSON (.json, array of objects format). For best results, ensure your CSV has a header row, and your JSON is a flat array of objects where each object is one row.
How large can my dataset be? ▼
Since everything runs in the browser, file size is limited by your device's available RAM. In practice, datasets up to ~10 MB (≈100K rows × 20 cols) work very comfortably. Files up to 50 MB may work but will be slower. For very large datasets, consider sampling before uploading.
Why does model training fail with "no numeric features"? ▼
ML models require numeric input. If all your feature columns are text/categorical, you need to encode them first. Go to the ⚙️ Features tab and apply One-Hot Encoding or Label Encoding to your categorical columns, then return to Models and try again.
Can I undo all cleaning steps and start fresh? ▼
Yes — press Ctrl+Z repeatedly to undo each step, or look for the Reset to Original button in the Clean tab which resets the dataset to its original uploaded state in one click.
How do I get the Python code for what I've done? ▼
Go to the 💻 Export Code tab. The app auto-generates a complete Python/scikit-learn script that mirrors your entire pipeline — loading, cleaning, feature engineering, and model training. Click Copy or Download .py.
The AI assistant says "no dataset loaded" — why? ▼
The AI only has dataset context after you've successfully uploaded a file. Upload a dataset first (you'll see the green status bar in the AI tab update with row/column counts), then the AI will be able to answer dataset-specific questions.
Can I compare results from different datasets? ▼
ModelMentor works with one active dataset at a time. To compare, open the app in two separate browser tabs and load a different dataset in each. Use the Export Code feature in both to get reproducible scripts you can run side by side in a notebook.
How do I share my analysis with a colleague? ▼
Two options: (1) Use the Share button in the header to copy a link. (2) Go to the 📄 Report tab and download a standalone HTML report file — your colleague can open it in any browser without needing ModelMentor.
Which ML algorithm should I start with? ▼
For a quick baseline, run Logistic Regression (classification) or Linear Regression (regression) first — they're fast and interpretable. Then add Random Forest for higher accuracy and feature importance insights. If you're unsure, ask the AI Assistant — it will recommend based on your specific data.
